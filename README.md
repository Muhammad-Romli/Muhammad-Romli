## About

I am a backend developer who builds APIs, command-line tools and small web projects. My current work centres on Python and Go, with a growing interest in search and AI-assisted tooling.

## Featured projects

| Project | Description |
| --- | --- |
| [ArachNet](https://github.com/Muhammad-Romli/ArachNet) | Go-based RSS feed aggregator for following blogs and reading updates in the terminal. |
| [Vector-Seek](https://github.com/Muhammad-Romli/Vector-Seek) | Semantic search project using embeddings and similarity search. |
| [Oculus](https://github.com/Muhammad-Romli/Oculus) | Frontend built around backend integration, with a cyberpunk visual style. |
| [Poke-Search](https://github.com/Muhammad-Romli/Poke-Search) | CLI REPL tool using API fetching, parsing and caching. |
| [static-site-generator](https://github.com/Muhammad-Romli/static-site-generator) | Markdown-to-HTML generator built from scratch as a learning project. |
| [AI-Agent](https://github.com/Muhammad-Romli/AI-Agent) | Early experimentation with agentic workflows and automation. |
